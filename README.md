# Проекты практики

В этом репозитории содержатся выполненные задания по практике, разделённые по папкам и веткам:

## Структура

* **`1/`** – Задание практики №1. Полное решение в этой папке.
* **`2/`** – Задание практики №2. Полное решение в этой папке.
* **`3/`** – Задание практики №3. Полное решение в этой папке.
* **`4/`** – Задание практики №4. Полное решение в этой папке.
* **`5/`** – Исходная папка для практических заданий №5…№8. Решения для каждого задания хранятся в отдельных ветках:

  * Ветка `task5` – решение задания 5
  * Ветка `task6` – решение задания 6
  * Ветка `task7` – решение задания 7
  * Ветка `task8` – решение задания 8
